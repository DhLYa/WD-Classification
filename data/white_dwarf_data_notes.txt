WHITE DWARF CLASSIFICATION: DATA NOTES
======================================

Task: binary classification of white dwarfs (1) vs other objects (0) using Gaia
photometry and astrometry, with labels set by spectroscopy rather than by
position in the colour-magnitude diagram.

2. FIELD-STAR QUERY (gaia_400pc.csv)
------------------------------------

Archive: ESA Gaia archive (https://gea.esac.esa.int/archive/), Gaia DR3.

Reconstructed from the 15 output columns. The SELECT list matches the file
exactly; the WHERE clause is the last full version written and should be
confirmed against the row count (see section 6).

SELECT
g.source_id,
g.phot_g_mean_mag - 5*log10(1000/g.parallax) + 5 AS g_mag_abs,
g.phot_bp_mean_mag - g.phot_rp_mean_mag AS phot_mag_dif,
g.parallax, g.parallax_error, g.parallax_over_error,
g.phot_bp_mean_mag, g.phot_rp_mean_mag, g.phot_g_mean_mag,
g.ra, g.ra_error, g.dec, g.dec_error,
ap.spectraltype_esphs AS class,
ap.classprob_dsc_combmod_whitedwarf AS white_dwarf_prob
FROM gaiadr3.gaia_source g
LEFT JOIN gaiadr3.astrophysical_parameters ap ON g.source_id = ap.source_id
WHERE g.parallax >= 2.5
  AND g.parallax_error/g.parallax <= 0.05
  AND g.astrometric_excess_noise < 1
  AND g.phot_g_mean_flux_over_error >= 50
  AND g.phot_bp_mean_flux_over_error >= 20
  AND g.phot_rp_mean_flux_over_error >= 20
  AND g.pmra_error/g.pmra <= 0.05
  AND g.pmdec_error/g.pmdec <= 0.05

Cut meanings:
  parallax >= 2.5                       within 400 pc (parallax in mas, d = 1000/parallax)
  parallax_error/parallax <= 0.05       parallax known to 5% or better
  astrometric_excess_noise < 1          clean astrometric solution
  phot_*_flux_over_error >= 50/20/20    good photometry in G, BP and RP
  pm*_error/pm* <= 0.05                 proper motion known to 5% (but see issue 2 in section 6)

Distance conversion: parallax >= 1000/d_pc
  10 mas = 100 pc, 5 mas = 200 pc, 2.5 mas = 400 pc, 1 mas = 1000 pc


3. COLUMNS IN gaia_400pc.csv
----------------------------

source_id            Gaia DR3 source identifier
g_mag_abs            absolute G magnitude, from apparent G and parallax
phot_mag_dif         BP - RP colour (renamed to bp_rp in the notebook)
parallax             mas
parallax_error       mas
parallax_over_error  parallax signal-to-noise
phot_bp_mean_mag     apparent BP magnitude
phot_rp_mean_mag     apparent RP magnitude
phot_g_mean_mag      apparent G magnitude
ra, ra_error         right ascension and its error
dec, dec_error       declination and its error
class                Gaia ESP-HS spectral type (O/B/A/F/G/K/M/CSTAR), null for
                     most sources. NOT the white dwarf label; overwritten with
                     0 for negatives in the notebook.
white_dwarf_prob     Gaia DSC white dwarf probability. EDA only, never a feature
                     (derived from the same photometry, leaks the label).


4. LABELS (spectroscopic sample)
--------------------------------

Labels come from SDSS spectra in gaiaedr3_wd_sdssspec, column spec_class
(strip whitespace first: FITS strings are space-padded).

Label 1, white dwarf:
  DA, DA:, DAB, DABZ, DAH, DAO, DAZ, DA_DQ,
  DB, DB:, DBA, DBAH, DBH, DBZ, DBAZ,
  DC, DC:, DO, DOX, DQ, DQ:, DQZ, pecDQ, hotDQ,
  DZ, DZ:, DZA, DZAB, DZB, DZBA, DZH,
  WD, WDpec, MWD, PG1159

Label 0, confirmed contaminant:
  STAR, QSO, GALAXY, CV

Dropped:
  UNKN, Unreli                  unknown or unreliable spectra
  DA_MS, DA_MS:, DC_MS, DB_MS   white dwarf + main-sequence binaries (blended photometry)

Excluded from features because they leak the label: Pwd, PHwd, and all
teff_*, logg_* and mass_* columns (derived assuming the object is a white
dwarf, or from colour-magnitude position).


5. BUILDING THE MODELLING DATASET
---------------------------------

Features (same set computed for both sources):
  g_mag_abs, bp_rp, bp_mag_abs, rp_mag_abs, parallax,
  phot_g_mean_mag, phot_bp_mean_mag, phot_rp_mean_mag

Absolute magnitude: M = m - 5*log10(1000/parallax) + 5   (parallax in mas)

Negatives from gaia_400pc.csv, cleaned in two steps:
  1. Remove any source_id that appears in the spectroscopic sample.
  2. Remove any source_id that appears in the full Gentile Fusillo catalogue.
     Using the photometric catalogue to CLEAN negatives is fine because Pwd is
     never fed to the model.

Residual contamination: white dwarfs missed by both catalogues (too faint or
distant) remain in the negatives. Expected well under 1%; this sets a soft
ceiling on achievable precision.

Then: combine positives and negatives -> train/test split -> undersample the
majority class in the TRAINING set only -> scale.

Models: logistic regression, random forest, XGBoost.
Metrics: PR-AUC, precision and recall on the white dwarf class.


6. KNOWN ISSUES AND CHECKS
--------------------------

1. 3,000,000-row cap. Exactly 3,000,000 rows matches the ESA Gaia archive limit
   for asynchronous queries by users who are not logged in. The file is
   probably truncated and, with no ORDER BY, likely biased by sky position
   (source_id encodes position).
   CHECK: run SELECT COUNT(*) with the same WHERE clause. If it is over
   3,000,000, re-run logged in (no row limit for registered users) or take a
   deliberate random subsample with "AND g.random_index < N".

2. Proper motion cuts. pmra_error/pmra <= 0.05 always passes when pmra is
   negative. Fix: pmra_error/ABS(pmra) <= 0.05 (same for pmdec). The cut also
   favours high proper motion stars; consider dropping it.

3. Data release IDs. The spectroscopic file has source_id (EDR3/DR3) and
   dr2_source_id. The field-star pull is DR3-keyed. Check every .isin() match
   uses the same release, or matches fail silently.

4. Proper motion feature. The spectroscopic file has no pmra/pmdec, so total
   proper motion cannot be a feature for positives. sqrt(ra**2 + dec**2) is
   NOT proper motion and was removed.

5. Contaminant population. Label-0 objects in the spectroscopic sample are only
   what SDSS happened to observe, not a representative field population. The
   field-star negatives partly offset this.

6. History. The first version used photometric labels from the Gentile Fusillo
   Gaia DR2 catalogue (Pwd). Those labels are defined by position in the
   colour-magnitude diagram, the same space as the features, which gave a
   circular PR-AUC of 1. Replaced by spectroscopic labels.
